# Mission 4 - How Programs Run

## Task 4.1 - Running a Python Program

I created a Python file named hello.py containing:

```python
print("Hello from Python")
```

I ran the program using:

```bash
python3 hello.py
```

Output:

```text
Hello from Python
```

This program uses the print() function to display text on the screen.

## Task 4.2 - Compiler vs Interpreter

| Feature | Compiler | Interpreter |
|---|---|---|
| How it works | Translates a program into another form, often machine code, before execution | Executes program instructions through an interpreter, often as it processes them |
| Output | Often creates a separate executable or compiled file | Often runs without creating a standalone executable |
| Example | C, C++ | Python (commonly described as interpreted) |
| Advantage | Compiled programs can execute efficiently | Convenient for testing and development |

## Learning

I learned how to create and run a Python program using Terminal and understood the basic difference between compilers and interpreters.
