# Mission 6 - Git and GitHub

## Task 6.1 - Basic Git Commands

| Command | Purpose |
|---|---|
| git init | Initializes a Git repository |
| git status | Shows the current status of files |
| git add | Stages files for a commit |
| git commit | Saves staged changes |
| git log --oneline | Displays commit history |

I practiced initializing a repository, checking its status, staging a file, committing changes and viewing commit history.

## Task 6.2 - Branching

I created a branch named update-about and added a My Learning section to my main README. I committed the changes on the new branch instead of directly modifying the main branch.

## Task 6.3 - Pull Request

I created a pull request to propose merging my update-about branch into main. A pull request allows changes to be reviewed before they are merged. I then merged the changes into the main branch.

## Task 6.4 - Git Glossary

| Term | Meaning |
|---|---|
| Repository | A project folder tracked by Git |
| Commit | A saved snapshot of changes |
| Branch | A separate line of development |
| Merge | Combines changes from different branches |
| Pull Request | A request to review and merge changes |
| Clone | Creates a local copy of a repository |
| Push | Sends local commits to a remote repository |
| Pull | Fetches and integrates changes from a remote repository |

## Learning

I learned how Git tracks changes, how to create and use branches, how commits save changes, and how pull requests are used to review and merge changes on GitHub.
