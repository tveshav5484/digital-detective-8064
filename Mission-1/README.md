# Mission 1 - Know Your Computer

## Task 1.1 - IPOS

IPOS stands for Input, Processing, Output and Storage.

| Stage | Example |
|---|---|
| Input | Typing text using the keyboard |
| Processing | The computer processes the typed characters and formatting |
| Output | The text appears on the screen |
| Storage | The document is saved on the SSD or hard drive |

## Task 1.2 - Hardware and Software

### Hardware

| Hardware | Role |
|---|---|
| Keyboard | Used to enter text and commands |
| Monitor | Displays visual information |
| CPU | Processes instructions and data |
| RAM | Temporarily stores data being used |

### Software

| Software | Role |
|---|---|
| macOS | Manages the computer and its resources |
| Google Chrome | Used to browse the internet |
| Python | Used to write and run programs |
| VS Code | Used to write and edit code |

## Task 1.3 - Computer-Based Systems

### 1. ATM
Purpose: Allows users to withdraw money, check balances and perform banking operations.

Input: ATM card, PIN and transaction details.

Output: Cash, receipt and transaction confirmation.

### 2. Traffic Signal System
Purpose: Controls traffic flow and helps manage road safety.

Input: Timers or sensors detecting vehicles.

Output: Red, yellow and green traffic lights.

### 3. Smart TV
Purpose: Displays television programs, videos and streaming content.

Input: Remote control commands and streaming data.

Output: Video and audio.

## Learning

I learned about the basic stages of how a computer works, the difference between hardware and software, and how computer-based systems use inputs to process information and produce outputs.
