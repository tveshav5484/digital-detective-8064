# Mission 2 - Learn Terminal

## Task 2.1 - Basic Terminal Commands

| Command | Purpose |
|---|---|
| pwd | Displays the current working directory |
| ls | Lists files and folders |
| ls -l | Displays a detailed listing |
| mkdir | Creates a directory |
| cd | Changes the current directory |
| touch | Creates an empty file |
| echo | Prints or writes text |
| cat | Displays file contents |
| cp | Copies files |
| mv | Moves or renames files |

## Task 2.2 - Mini Practice

### 1. What does pwd do?
It displays the current working directory, showing where I am located in the file system.

### 2. What is the difference between > and >>?
The > operator writes text into a file and replaces existing content, whereas >> appends text to the end of a file.

### 3. What is the difference between cp and mv?
cp creates a copy of a file, while mv moves or renames a file.

### 4. What does cat do?
cat displays the contents of a file in the Terminal.

## Task 2.3 - Flags and Pipes

- ls -a displays hidden files as well as regular files.
- ls -lh displays detailed information with human-readable file sizes.
- ls -l | head -3 displays the first three lines of the detailed listing using a pipe.

## Task 2.4 - Package Managers

A package manager is a tool used to install, update and manage software.

Homebrew is a package manager commonly used on macOS. The command brew --version checks the installed version, while brew list displays the packages managed by Homebrew.

## Learning

I learned how to navigate the file system using Terminal, create and manage files, use commands with flags, connect commands using pipes, and understand the purpose of package managers.
