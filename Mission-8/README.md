## Mini Project - Number Converter

I created a Python program that takes a decimal number as input and converts it into binary and hexadecimal.

### Code

```python
number = int(input("Enter a decimal number: "))
print("Binary:", bin(number)[2:])
print("Hexadecimal:", hex(number)[2:].upper())
```

### How to Run

1. Open Terminal.
2. Navigate to the folder containing the file.
3. Run the command:

```bash
python3 number_converter.py
```

4. Enter a decimal number to see its binary and hexadecimal conversions.
