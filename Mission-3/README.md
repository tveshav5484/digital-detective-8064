# Mission 3 - Understand the Operating System

## Task 3.1 - System Exploration

| Command | Purpose |
|---|---|
| sw_vers | Displays macOS version information |
| whoami | Displays the current username |
| df -h | Displays disk storage information in a readable format |
| uptime | Displays how long the system has been running |

I used these commands to explore my operating system and learn about my system information and storage.

## Task 3.2 - Processes

The ps command displays information about running processes. I used ps -ax | head -10 to observe a selection of processes running on my computer. A process is a program or task that is currently being executed.

## Task 3.3 - Paths and Permissions

File permissions determine who can read, write or execute a file.

- r stands for read.
- w stands for write.
- x stands for execute.
- d indicates a directory.

Permissions are divided into three groups: owner, group and others.

## Task 3.4 - Responsibilities of an Operating System

| Responsibility | Explanation |
|---|---|
| Process management | Manages programs that are currently running. |
| Memory management | Allocates RAM to different programs. |
| File management | Organizes files, folders and their access. |
| Device management | Controls devices such as printers, keyboards and displays. |
| User interface | Provides ways for users to interact with the computer through graphical interfaces or commands. |

## Learning

I learned how an operating system manages running programs, memory, files, devices and user interaction. I also explored my Mac using Terminal commands and learned about file permissions and processes.
